Самостоятельная регистрация

Ограничения на загрузку

Действует сразу для всех — без перезапуска сервера. «Запрещённые» — список того, что нельзя прислать (всё остальное можно); «Разрешённые» — наоборот, можно только то, что в списке. Расширения — через запятую или пробел, без точки (exe, bat, zip...).

Все файлы, которые когда-либо отправляли через личную переписку, общую комнату или рассылки. Удаление стирает файл с диска сервера навсегда — ссылка на него в старой переписке перестанет открываться, но само сообщение никуда не денется.

Клиенты и обновления

Что выложено на сервере

Версии из папок updates/win7 и updates/win10. Если пусто — сборки ещё не выложены, и клиенты обновляться не будут.

Кто сейчас в сети

Версия видна только у тех, кто сейчас подключён. «Обновить» скачает новую версию на эту машину и перезапустит приложение — сотрудник получит предупреждение за 15 секунд. «Журнал» запросит с машины её локальный файл ошибок: туда попадает то, чего нет в общих логах — падения окон и сбои обновления.

Сертификат сервера


      

        
Что сейчас действует

        

          Пока сертификата нет, пароли, переписка и файлы идут по сети открытым текстом — их видит
          любой, кто может слушать сеть между сотрудником и сервером.
        

        
Загрузка…

      


      

        
Заменить сертификат

        

          Файл .pfx или .p12 — тот, что выдаёт удостоверяющий центр
          домена. Конвертировать ничего не нужно. Файл сначала проверяется (пароль, срок, цепочка)
          и только потом заменяет действующий: испортить работающий сервер загрузкой не того файла
          нельзя.
        

        

          Эта страница открыта по http. Закрытый ключ уйдёт на сервер незашифрованным — его
          сможет перехватить любой, кто слушает сеть. Для самой первой установки это допустимо
          (иначе её не сделать), дальше — открывайте панель по https.
        

        

          
          
          
        

        

      


      

        
Убрать сертификат

        

          Удаляет файл из хранилища сервера. Работающий сервер останется на https до перезапуска —
          выключить шифрование на ходу нельзя. Нужно, только если сертификат положили по ошибке.
        

        
      

    


    

      
Логи

      

        

          Входы/выходы, срабатывания защиты от подбора пароля и ошибки сервера — плюс ошибки,
          присланные с рабочих мест сотрудников (сбои в приложении на их ПК). Хранится по дням в
          файлах на сервере (папка logs/), здесь — только просмотр.

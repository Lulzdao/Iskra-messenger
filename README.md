# Искра

Корпоративный мессенджер Липецкстата: работает на своём сервере в локальной сети, наружу ничего не
отправляет. Личная переписка, группы, общая комната, объявления на всю организацию, передача файлов.
Клиент — обычное приложение для Windows (7, 8.1, 10).

Состоит из двух частей:

- **[`mini-messenger/`](mini-messenger/README.md)** — сервер (Node.js + WebSocket + SQLite) и
  веб-панель администратора: сотрудники, отделы, права, переписки, файлы, логи.
- **[`desktop-client/`](desktop-client/README-desktop-client.md)** — приложение для сотрудников
  (Electron), собирается в `.exe`-установщик.

Хотите понять, как это устроено внутри — что происходит между приложением сотрудника и сервером от
ввода пароля до появления сообщения у собеседника — читайте
**[«Как это работает»](КАК-ЭТО-РАБОТАЕТ.md)**. Написано без расчёта на технические знания.

## С чего начать

Сервер работает на Windows Server 2016 с Node.js 22 (на Linux — тоже, разницы в коде нет):

```bat
cd mini-messenger
npm install
copy bootstrap-admin.example.js bootstrap-admin.js   :: логин и пароль первого администратора
npm start
```

Откройте `http://адрес-сервера:3000` — это панель администратора. Первым делом
**выключите самостоятельную регистрацию** («Пользователи» → верхний блок) и заведите сотрудников
вручную.

Затем соберите клиент и раздайте установщик — подробности в
[README клиента](desktop-client/README-desktop-client.md).

## Важно перед боевым использованием

**Включите шифрование канала.** Сервер умеет работать по HTTPS сам, но только если ему передали
сертификат — иначе пароли, переписка и файлы идут открытым текстом. Сертификат берётся у
удостоверяющего центра вашего домена и загружается как есть, `.pfx`-файлом, прямо в панели
администратора (раздел «Сертификат») — конвертировать ничего не нужно. Там же он потом и меняется:
подробности в [README сервера](mini-messenger/README.md).

Включено ли шифрование, видно и в самом клиенте: на экране входа и рядом с именем сотрудника.

Вся переписка организации лежит в одном файле `mini-messenger/messenger.db` — настройте его
резервное копирование.
